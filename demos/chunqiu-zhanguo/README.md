# 春秋战国 · 疆域与兼并

公元前 770 年至公元前 221 年，五百五十年间，百余诸侯并吞为七雄，终归于一。

## 这个演示在做什么

一张逐年推进的疆域图。拖动时间轴或点播放，可以看到每个区域的归属如何变化：某年某国被灭，颜色随之覆盖；灭国时弹出档案，说明是谁灭的、依据什么；关键战役在图上以点位标出。

覆盖范围是从陇西到岭南的 38 个历史区域，从宗周、晋、齐、楚这些大国到滕、薛、小邾这类泗上小国。势力共 29 个，含「无主」这一虚拟势力，用于表示尚未被任何诸侯有效控制的地带。

国名标注优先落在势力都城所在区域；若该区尚未易手，则退而落在其当前最大辖区。因此 `S` 里的 `cap` 应指向该势力当时的政治中心，而不是任意一块领地。

## 文件结构

| 文件         | 职责                                             |
| ------------ | ------------------------------------------------ |
| `index.html` | 页面骨架：地图容器、侧栏、时间轴控件             |
| `data.js`    | 全部数据：势力、区域多边形、归属年表、战役、阶段 |
| `app.js`     | 渲染层：投影、绘制、交互、灭国档案               |
| `style.css`  | 本演示的样式                                     |

改数据只碰 `data.js`。改绘制只碰 `app.js`。两者不交叉：`app.js` 里没有一处坐标常量，`data.js` 里没有一行 DOM 操作。

## 坐标系

所有坐标是 `[经度, 纬度]`，WGS84 度单位，不做真实投影换算。投影在 `app.js` 里用一组线性参数把经纬度映射到 SVG 画布：

```js
const LON0 = 102,
  LAT0 = 42.9,
  SX = 44,
  SY = 34.2,
  OY = 10;
const px = (lon, lat) => [(lon - LON0) * SX + 12, (LAT0 - lat) * SY + OY];
```

这意味着图上形状是等距圆柱投影的一段裁切，不是墨卡托，也不是等积投影。对这个纬度的区域而言两者差别不大，但不要拿它去算真实面积。

## 史料处理

年份取通行编年，主要依据以下文献与工具书：

- 《史记》各世家、列传
- 《左传》
- 《战国策》
- 谭其骧《中国历史地图集》

区域边界是示意性的，参考山川与郡界的大致走向，不代表精确的考古复原。判断标准是「能看出层次」而不是「经得起测量」：比如中原的周、郑、宋、卫之间必须能分辨出蚕食的先后，而单个县的界线不在考虑范围内。

有几个年份存在异说，本演示的取舍如下。

- 楚灭申系于前 688 年（《左传·庄公六年》楚文王伐申），灭息系于前 680 年，《左传·哀公十七年》"实县申息"追述其事。二者不合并，因楚文王前 689 年方即位。
- 晋灭耿、霍、魏系于前 661 年（《左传·闵公元年》，晋献公十六年），非前 672 年。
- 桂陵之战系于前 353 年，前 354 年为魏围邯郸之年。
- 秦取楚汉中、置汉中郡系于前 312 年丹阳之战后（《史记·秦本纪》《楚世家》），非前 314 年。
- 楚灭陈系于前 478 年（《左传·哀公十七年》"秋七月己卯，楚公孙朝帅师灭陈"），与陈湣公卒年一致。
- 楚灭邾、小邾系于前 261 年，旧说另有前 261 至前 256 年之间、前 260 年前后诸说。
- 越亡之年取前 306 年（楚怀王乘越内乱尽取故吴之地）。也有系于前 334 年楚威王杀越王无疆者，但越此后仍有君，国未即亡，故前 334 年仅记事件、不改归属。
- 越灭滕之说（越王朱勾）姑存其事而不改归属，因滕寻复国，前 286 年灭于宋的记载更为通行。
- 薛亡之年有前 418 年齐取其地、前 321 年齐威王封田婴于薛、前 298 年前后诸说，本演示取前 418 年入齐。
- 楚置黔中郡年月史无明文，姑系于前 330 年，前 277 年秦取其地。
- 卫的存续延至秦二世废卫君角，故前 221 年不并入秦，图上保留卫国。
- 代在前 228 年公子嘉自立为代王后重新独立，前 222 年被秦所灭，中间不视为赵地。
- 中山在前 406 年灭于魏、前 380 年复国、前 296 年灭于赵，故其存续轨迹中间有一段缺席，属史实而非数据缺失。

## 已知的简化

这些是有意为之，不是遗漏。

- 同一区域内部不区分郡县，一个区域只有一个归属。因此「某国在其境内设郡」这类事件不会改变颜色。
- 迁都只改 `S` 里的 `cap` 指向，图上不移动都城点位。
- 若干小国（如极、邿、鄟）未单列区域，合并进所在大区。
- 边界随时间推移本应连续变化，这里按事件跳变，中间过程不做插值。

## 想改点什么

先读[数据格式说明](../../docs/data-format.md)，再改 `data.js`。改完运行：

```bash
node scripts/check.mjs
```

它会校验区域键是否闭合、势力引用是否存在、年份是否落在区间内。通过了再提 PR。
