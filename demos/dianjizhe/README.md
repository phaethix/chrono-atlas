# 奠基者 · 周与中华文明的底色

《奠基者》第三卷的整卷骨架。六章压成六节，一节回答一个问题。

## 六节

| 节   | 问题                                   | 对应章节 |
| ---- | -------------------------------------- | -------- |
| 忧患 | 胜利之后，周人为什么先感到恐惧？       | 第一章   |
| 天命 | 周人凭什么说天命归自己？               | 第二章   |
| 封建 | 封什么，建什么，为什么说它是制度创新？ | 第三章   |
| 宗法 | 宗法与封建怎样合为一个家？             | 第四章   |
| 礼乐 | 礼和乐各自解决什么问题？               | 第五章   |
| 根本 | 中华文明为什么"超级稳定"？             | 第六章   |

卷首列了周人的四套制度——井田、封建、宗法、礼乐。这是全卷的落点：四者环环相扣，配套互补，才构成一个自洽的系统。

## 为什么不是地图

这一卷问的是"凭什么"和"怎么办"，不是"疆域在哪里"。书里真正的地理只有封国的方位（宋、卫、鲁、晋、燕、齐），而且是为了说明布局，不是为了画边界。硬画一张西周疆域图，等于把制度史降格成势力图。

所以用分节视图：一节一个问题，节内几条并列。六节按原书章序排，不另立框架。

## 六节的骨架

**忧患**：周公见殷商贵族助祭而惊悚，由此追问天命能否长保。周以小邦敌大邦，靠笼络、经营南国、挖墙脚三步翦商；胜利太快，反而暴露危机。答案是"天命即授权"：可以授予，就可以收回，收回就是革命。

**天命**：世界通例是君权神授，周人独称君权天授。神授是宗教性的，天授是伦理性的；天不是人格神，是人的父母。再由"天视自我民视"把天授偷换成民授，落到"以德治国"。何尊的"恭德裕天"与"宅兹中国"，是这条线唯一的物证。

**封建**：封是划疆，建是授土、授民、授爵。周天下不是王朝，是"一个天下，许多邦国，一个天子，许多元首"。宋为怀柔，卫为监视，鲁、晋、燕是远距离殖民；齐、鲁在东夷老窝，晋、燕近戎狄。井田则是把土地和民生捆在一起的经济配套。

**宗法**：父家长制、一夫一妻多妾制、嫡长子继承制，三要素合成宗法。宗法与封建合二为一，天下成了家，也成了"姬周株式会社"。士是这套制度的必然产物：大夫不能再封，大夫之子无爵可袭，只能做士。君子与小人的本义，是"君主之子"与"小宗之人"。

**礼乐**：礼辨异，乐统同；礼维持秩序，乐安定人心。名分决定名器，九鼎八簋、八佾、十二旒各有差等。礼只认秩序，不管是非，所以有南蒯这样的"爱国贼"。但伦理也要给人性留口子，上巳节就是那个口子。

**根本**：一个内核（群体意识），两只翅膀（忧患心理、乐观态度），三大精神（人本、现实、艺术），四种制度（井田、封建、宗法、礼乐）。这是周人的遗产，也是中华文明"超级稳定"的解释。

## 取舍

- **不补书里没有的年代。** 武王伐纣、周公摄政、分封诸侯的具体年份，书里不给，这里也不写。
- **周公是否摄政称王，三说并存。** 书里明说学界争议很大，页面只取"主要领导人"这一最低共识，不裁断。
- **井田制如实存疑。** 书里说"根本就是一种想象或者理想"，页面照写，不把它当成已经证实的制度。
- **"以德治国为周人独创"的证据链很短。** 主要系于何尊一器，其"最早"依赖专家核验；页面写作"物证"，不写成定论。
- **礼乐的具体仪节从简。** 乡饮酒礼、冠礼、上巳节各取一句，细节留给原书。
- **这是本书的主张。** 群体意识、早熟的儿童、超级稳定，都是易中天的判断，不是学界共识；页面不替他把话说满。
