# 国家 · 从部落到文明

《国家》第二卷的整卷骨架。六章压成四节，每节回答一个问题。

## 四节

| 节     | 问题                           | 对应章节       |
| ------ | ------------------------------ | -------------- |
| 城市   | 国家为什么不同于部落？         | 第二章         |
| 两条路 | 为什么东方是君主，希腊是民主？ | 第一、二、三章 |
| 图腾   | 部落变成国家，图腾往哪里去？   | 第四、五章     |
| 三代   | 夏商周为什么不能叫三朝？       | 第六章         |

卷首列了人类最早的五大文明——埃及、美索不达米亚、哈拉巴、克里特、夏——它们都在距今三四千年前建国。这是全书的前提：建国不是哪一家的选择，是共同的门槛。

## 为什么不是地图

这一卷问的是「国家为什么会有」，不是「疆域在哪里」。书里真正的地理只有一句关键：二里头被认为是中晚期的夏都，我国最早的城市遗址在那里。其余全是形态与制度的比较，画成地图反而是硬凑。

所以用的是分节视图：一节一个问题，节内几条并列。两条就两列（城与市），三条就三列（君主、民主、共和）。

## 四节的骨架

**城市**：国就是或，囗是围墙，戈是兵器；加土为域，加囗为國。城是政治的，市是商业的；上海拆了城墙反而更旺，自由也是城市的特质。

**两条路**：东方各国都走君主制，埃及法老是荷鲁斯的儿子，中国皇帝是天的儿子；希腊选民主，罗马选共和。海图不同，要素相同。

**图腾**：埃及把图腾变成神，祭司坐大，前 1085 年赫里霍尔直接采用王室头衔；罗马把图腾变成法，以法代图腾棋高一着；中国把图腾变成祖宗，家国一体，认祖归宗。希腊把宗教变成艺术，印度把巫术变成宗教，中国两头都没走。

**三代**：夏是草创，商是探索，周是形成。真正的王朝开始于秦，所以三代只能叫三代，不能叫三朝。

## 取舍

- **不给商、周纪年**。书里只给了夏的约前 2070，还注明依据夏商周断代工程、仅供参考；商周的起始年书中未给，这里不补。
- **夏的存在如实存疑**。页面上写的是「二里头被认为是中晚期的夏都」，没有说成定论。
- **只取与「国家」有关的线索**。希腊的哲学、印度的宗教在书里篇幅不小，这里只保留它们与建国路径相关的部分。
- **不画费城**。第三章从雅典讲到费城，线索很长；页面只取了「民主—共和」这条主轴，制宪一段留给原书。

## 想改点什么

改内容只碰 `data.js`，改版式只碰 `app.js` 与 `style.css`。改完运行：

```bash
node scripts/check.mjs
```

它会检查每节的 `key` 是否重复、`items` 与 `points` 是否为空、`STEPS` 是否指向真实存在的节。
