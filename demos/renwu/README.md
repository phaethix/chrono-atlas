# 人物与阶段 · 从蛙到龙

《祖先》第一卷的人物图。十五个人，六个阶段，一条继位的链。

## 为什么没有族谱

因为本书说没有。

第一卷第六章讲得很直接：黄帝、颛顼、帝喾、尧，**无血缘关系，更不是祖孙父子**。后记里又说，女娲伏羲「人首蛇身，甚至是夫妻或兄妹」这类说法，基本上被学界认同，却其实是谎言。

所以这张图不画树。它把人物按阶段排成六列，只用一条虚线连出继位的先后；被本书否定的旧说另画成红色点线，标一个「不取」。

## 六个阶段

| 阶段     | 形态 | 代表 | 本书的说法                               |
| -------- | ---- | ---- | ---------------------------------------- |
| 原始群   | 点   | 夏娃 | 分散、弱小、自生自灭，把猿群变成了人群   |
| 母系氏族 | 面   | 女娲 | 只知其母；娲读如蛙，蛙腹多子             |
| 父系氏族 | 面   | 伏羲 | 蛇取代蛙，男人要确认父系的继承权         |
| 部落     | 片   | 炎帝 | 牧羊人自西东进，图腾由羊换牛             |
| 部落联盟 | 圈   | 黄帝 | 以氏别贵贱，用轩冕换和平，龙旗是拼出来的 |
| 国家     | 国   | 启   | 禹的儿子继位，世袭取代推举               |

黄帝放在「部落」一列，因为本书把他当作晚期部落的联合体，不是国家；「联盟」一列留给尧舜禹。

## 四类线

- **黄色虚线**：继位。五帝之间只有先后，没有血缘，所以这条线是图的主干。
- **青色实线**：血缘。全书只画两条：鲧 → 禹（本书认为鲧是禹的母亲，不是父亲）、禹 → 启。
- **红色实线**：敌对与杀。阪泉、涿鹿。
- **红色点线 + 叉**：本书明确不取的旧说。女娲与伏羲的夫妻关系、炎黄同出少典的兄弟关系，都属此列。

## 演化进程

右栏七步，从左到右走一遍：夏娃 → 女娲 → 伏羲 → 炎帝 → 黄帝 → 尧 → 启。每步一句旁白，说的是形态怎么变，不是谁生了谁。

## 收人标准

只收本书点到名、且有明确说法的人。十五个：夏娃、女娲、伏羲、炎帝、黄帝、蚩尤、颛顼、帝喾、尧、舜、禹、鲧、契、弃、启。

《史记》里那些把谱系接起来的人——玄嚣、昌意、蟜极、穷蝉、敬康、句望、桥牛、瞽叟、嫘祖、昌仆——本书一次也没提，这里一个也不收。

## 数据在哪

- `corpus/people/shanggu.js`：十五个人物，身份与按语都来自书中原话的转述。
- `corpus/relations/shanggu.js`：十九条边，每条带 `claim`（本书采信 / 本书不取）、`src` 与 `source`（第几章）。
- 本目录 `data.js`：阶段划分、人物归属、七步旁白。

## 已知的取舍

- **不写生卒年**。本书不给这些人年份，传统纪年（如黄帝前 2698 年）是后世推算，不取。
- **颛顼、帝喾没有关系边**。本书只说他们是五帝之二、之三，与前后无血缘；图上就只能是一个孤立的节点。
- **契、弃与尧只有君臣关系**。本书说他们任民政部长、农业部长，没有取《史记》的父系出身之说。
- **蚩尤有两条红线**。敌对与杀分开画：涿鹿是两国交战，杀是战后的处置。

## 想改点什么

改人物与关系只碰 `corpus/`，改阶段与排布只碰本目录的 `data.js`。改完运行：

```bash
node scripts/check.mjs
```

它会检查关系两端是否存在、`claim` 与 `kind` 是否在词表内、亲子是否成环、`STEPS` 是否指向真实人物。
