# 三代 · 草创、探索、形成

《国家》第二卷的骨架：夏、商、周不是三个王朝，是三个民族、三个阶段、三种文明。

## 这一页画什么

不是地图。本卷问的是「国家为什么会有」，不是「疆域在哪里」。所以画的是三样东西：

- **顶上一串**：点、面、片、圈、国。启废禅让，圈变成国，国家从此登场。
- **中间三列**：夏、商、周各一列，形态、器物、制度逐条对照，列与列之间是取代。
- **底下一对**：图腾往哪里去。埃及把它变成神，中国把它变成祖宗。

## 三列的出处

每一条都能回到原书，标在卡的右下角。

| 列  | 要点                                                     | 出处       |
| --- | -------------------------------------------------------- | ---------- |
| 夏  | 部落国家；二里头为中晚期夏都；陶器刻符已近文字；启废禅让 | 第五、六章 |
| 商  | 部落国家联盟；甲骨与钟鼎；青铜礼器狞厉的美               | 第六章     |
| 周  | 半独立主权国家联盟；武王伐纣；何尊「宅兹中国」           | 第六章     |

底部对照：埃及「图腾变神，祭司坐大」（第四章），中国「图腾变祖宗，祖与社是牌位」（第五章）。

## 几个容易读错的地方

- **三代不是三朝**。本书的判断：夏是部落国家，商是部落国家联盟，周是半独立主权国家联盟。真正的王朝开始于秦。
- **夏的存在有争议**。本书的态度是「没有证据证明夏并不存在」，同时承认考古证据不足；二里头只说是「被认为是」夏都。
- **不给商周纪年**。书里只给了夏的约前 2070，并注明依据夏商周断代工程、仅供参考；商、周的起始年书中未给，这里也不补。

## 数据在哪

`demos/sandai/data.js`：`RIBBON`（点面片圈国）、`COLUMNS`（三列）、`LINKS`（取代关系）、`CONTRAST`（埃及对中国）、`STEPS`（三步进程）。

这一卷没有人物节点，也没有多边形，所以不引用 `corpus/`。

## 想改点什么

改内容只碰 `data.js`，改版式只碰 `app.js` 与 `style.css`。改完运行：

```bash
node scripts/check.mjs
```

它会检查 `COLUMNS` 的键是否重复、每列是否有 `facts`、`STEPS` 是否指向真实的列。
