# 祖先 · 从蛙到龙

公元前 7000 年至公元前 1900 年。《易中天中华史》第一卷《祖先》的六章，摊在同一张地图与同一条时间轴上。

## 这个演示在做什么

第一卷不写疆域。它讲的是「点、面、片、圈、国」：原始群、氏族、部落、部落联盟、国家，五种组织形态依次放大，代表分别是夏娃、女娲、伏羲、炎帝黄帝、尧舜、夏启。这些都不是国家，没有边界可画。

所以这张图和《春秋战国》不是一回事：

- 地图涂的是**考古学文化区**，不是政权版图。仰韶、大汶口、红山、良渚各占几块地，颜色变了表示文化面貌变了，不表示谁征服了谁。
- 事件分三层，侧栏用标签标出证据性质：**考古**（遗址与器物）、**传说**（神话与后世追述）、**文献**（成文记载）。三者混读是这一卷最容易犯的错。
- 术语跟着换：没有「灭」，只有「代」；没有「兼并档案」，只有「层位档案」。这些词写在 `META.terms` 里，不写死在渲染层。

## 六章与地图的对应

书里的六章按组织形态排，不按年代排。演示把两者叠在一起：横向是章节，纵向是考古学文化的实际推移。

| 章          | 书里的命题                       | 演示中的代表 | 区间              | 图上发生的事                                                       |
| ----------- | -------------------------------- | ------------ | ----------------- | ------------------------------------------------------------------ |
| 一 夏娃造反 | 从猿到人，性成为文化，原始群是点 | 夏娃         | 前 7000 — 前 5000 | 裴李岗的粟作聚落；贾湖骨笛；大地湾彩陶                             |
| 二 女娲登坛 | 母系氏族，生殖崇拜，蛙与月亮     | 女娲         | 前 5000 — 前 4000 | 满天星斗：仰韶、红山、河姆渡、马家浜同时出现；半坡人面鱼纹         |
| 三 伏羲设局 | 父系代兴，蛇与羊，祭坛分方圆     | 伏羲         | 前 4000 — 前 3300 | 庙底沟花瓣纹铺开半个中国；牛河梁筑坛；大汶口八角星                 |
| 四 炎帝东征 | 羌人东进，图腾取代生殖崇拜，部落 | 炎帝         | 前 3300 — 前 2600 | 良渚、马家窑、屈家岭、石峡并起；良渚古城；姜姓牧羊人入中原（传说） |
| 五 黄帝出场 | 联合体、氏与轩冕、龙旗           | 黄帝         | 前 2600 — 前 2300 | 阪泉、涿鹿（传说）；中原转入龙山；海岱蛋壳黑陶；石家河玉人         |
| 六 尧舜下课 | 部落联盟，禅让即不得不让，启建夏 | 尧舜         | 前 2300 — 前 1900 | 陶寺观象台；石峁石城；良渚崩溃；二里头兴起                         |

每个阶段在地图上不是靠人物标记，而是靠文化区的此消彼长。人物的活动范围没有落点，只在纪事里说话——这是有意为之：把黄帝画在某个多边形里，等于替他编了一个考古学文化。

## 数据里有什么

39 个地理区域，17 支考古学文化，46 条事件，9 处遗址与战场。

区域用山川命名（陇西、关中、陕北、晋南、汶泗、淄潍、江汉、江东一线），与《春秋战国》共用同一套多边形。两张图的海岸线与河流能对得上，读者不至于以为在看两个国家。

每支文化在 `S` 里有两个额外字段：`sym` 是标志物（仰韶的鱼蛙纹、红山的玉龙、良渚的玉琮、龙山的蛋壳黑陶），`cap` 是命名地所在区域。标志物进图例与悬停卡片，因为它就是这一卷的论证材料——蛙、蛇、羊、牛、龙，一步一个符号。

遗址与战场共用 `BATTLES`，靠 `kind` 区分：`battle` 画兵锋，`site` 画空心方点。阪泉、涿鹿是传说里的战场，大地湾、半坡、牛河梁、莫角山、观象台、皇城台、宫城是挖出来的遗址，两者在同一张图上并存，正是要读者自己分辨。

标记不写遗址全名，写的是具体遗迹：莫角山是良渚古城的台城，观象台在陶寺，皇城台在石峁，宫城在二里头。因为这些文化本来就以遗址命名，标一个「陶寺」压在「陶寺」上，只会让人以为标签重了。

## 年份怎么定

这是这个演示最需要交代的地方。

- **考古事件**按通行断代取整到百年，误差通常在正负一百年内。仰韶前 5000—前 3000、大汶口前 4300—前 2500、良渚前 3300—前 2300、龙山前 2600—前 2000、二里头前 1900 起，都是教科书与考古报告里的常见区间。碳十四校正后的具体数字各家不同，这里取的是「能排出先后」的那一档精度。
- **传说事件**没有年份。女娲、伏羲、炎帝、黄帝、尧舜在文献里只有先后，没有纪年。演示把它们系在所属阶段的代表年上，例如涿鹿系于前 2600、禅让系于前 2200。**这些年份是演示约定，不是史载**，阅读时请看侧栏的「传说」标签。
- **六章的起讫**同样是约定，按考古学文化的转折点切分，不是书里的原话。

## 异说与取舍

- **二里头与夏**。前 2070 年启继位，用的是夏商周断代工程的年代；二里头是否即夏都，学界仍有争论。演示把「启建夏」记为文献（`src:'text'`），把二里头兴起记为考古，两者不合并成一条。
- **良渚是不是国家**。良渚古城有城墙、水利与大量玉礼器，常被称作「早期国家」。演示只说「国家的雏形」，不称王朝。
- **涿鹿与阪泉的地望**。传统说法在今河北涿鹿一带，也有其他考订。演示按传统地望定点，并标为传说。
- **炎帝与神农**。书里说「也许是一个，也许不是」。演示不合并，只取「炎帝族自西入中原」这一层。
- **伏羲的族属**。东方夷族、南方蛮族都有说法。演示不给伏羲划地盘，只在纪事里记他的符号变迁。
- **红山之后**。前 2900 年起燕辽转入小河沿文化，演示把这两块地退回「未详」，因为再往下细分就超出这一卷的范围了。

## 已知的简化

这些是有意为之。

- 一个区域只有一个文化。文化内部的类型与地方变体（半坡、庙底沟、大河村）不单独上色。
- 文化边界按河流与山脉示意，不代表发掘所见的确切分布界。判断标准是「能看出先后与方位」，不是「经得起测量」。
- 皖南、赣鄱、黔西、辽东四块始终留作「未详」。不是没有人，是这一卷没有可判定的文化归属，宁可留白。
- 传说人物的迁徙路线不画。地图只承载能落到具体区域的文化归属。
- 图的起点是前 7000 年，不是书里大事年表的前 390 万年。旧石器时代没有可比的区域文化，画不出来。

## 底图的一处修正

这套多边形原本为《春秋战国》而画。搬到史前题材后，大面积同色把底图的接缝暴露了出来：

- 冀中（约 114.3—117.3°E、35.9—38.8°N）原本没有区域，五个多平方度的空白夹在河内、太行、燕蓟之间。本演示补了「冀中」一区。
- 另有五处三角形空洞，是三个相邻多边形各占一条边、谁也没有覆盖中间那块造成的。补法是给其中一区插一个缺失的顶点：冀北、晋南、关中、汉中、江南各加一个点后，接缝闭合。

这类错误在多色疆域图里会被当成「国界」而不易察觉，换成大面积同色就一目了然了。
