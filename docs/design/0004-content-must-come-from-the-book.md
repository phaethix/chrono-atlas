# 0004 内容以所据之书为准

- 状态：已采纳
- 日期：2026-10-25

## 背景

第一卷的演示做出来之后，回头核对了一遍：图上的人、文化、年代，有多少真在书里。

结果不好看。

- 22 个人物里，11 个书中一次也没出现：玄嚣、昌意、蟜极、穷蝉、敬康、句望、桥牛、瞽叟、嫘祖、昌仆、挚。他们来自《史记》，不来自这本书。
- 17 支考古学文化里，10 支书中没提过：良渚、龙山、大汶口、河姆渡、马家浜、屈家岭、石家河、大溪、宝墩、石峡。
- 46 条事件里，多数是按通行断代自行编排的年代，书里没有。
- 更严重的是结论方向：那张图画了一条五帝世系，而本书第六章明说「黄帝、颛顼、帝喾、尧，无血缘关系，更不是祖孙父子」。**图与书的主张相反。**

## 决定

四条，按优先级：

1. **一条内容要么能在所据之书中找到，要么不收。** 书里没有的人、地点、年代、文化，一律不进数据。
2. **关系边标出本书的态度。** 新增 `claim`：`book` 采信，`rejected` 明确不取。`rejected` 必须写 `note` 说明理由，否则图上只剩一个没有来由的叉。
3. **不补书里没有的东西。** 生卒年、文化分布、年代序列，书不给就不写；宁可图上少一层，也不拿别的书来填。
4. **书与史冲突时以书为准**，并在演示的 README 里写明「这是本书的主张」，不让读者误以为是学界共识。

## 后果

- **第一卷的文化区图下架**（`demos/zuxian/`）。本书没有文化分布，也没有那套七千年的年代序列，这张图在「以书为准」下无法成立。代码留在这里的提交历史里，等有符合书的形态再重做。
- **五帝世系改成「人物与阶段」**。本书否定五帝血缘，就不该出现族谱；改成六列阶段加一条继位链，血缘只画书中认的两条（鲧→禹、禹→启），被否定的两说（女娲伏羲夫妻、炎黄兄弟）画成红点线并标「不取」。
- 第一卷从 22 人 35 边降到 15 人 19 边，46 条事件降到 7 步进程。

## 代价

- **内容密度下降。** 第一卷现在只有十五个人、十九条边，远不如之前那张图热闹。热闹是借来的。
- **录入会变慢。** 每一条都要回书里找依据，找不到就不写。二十四卷按这个速度，是年为单位的事。
- **书的说法本身有争议。** 以书为准，等于把易中天的判断放在图上，比如「鲧是禹的母亲」。这一点必须在 README 里挑明，不能伪装成定论。

## 不做

- 不把书外的补证塞进 `note` 混过去。`note` 只写本书的理由。
- 不因为「大家都知道」就默认某条史料成立。
- 不为凑数保留没有出处的节点。孤立的人物可以留着（颛顼、帝喾就没有边），但要说明为什么孤立。
